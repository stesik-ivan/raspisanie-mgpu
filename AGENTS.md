# Расписание МГПУ — правила проекта

Веб-приложение (PWA) с расписанием занятий для всего МГПУ: институты ВО и колледж (ИСПО).
Сейчас делаем **демо дизайна и функционала** для руководства. Сервера нет, данные выдуманные.
Если демо одобрят, подключаем PocketBase на сервере МГПУ и импорт из Excel учебных частей.

Общие правила работы лежат в `~/Documents/Codex/AGENTS.md`. Этот файл их дополняет, но не отменяет.

## Роли

| Роль | Вход | Что видит и делает |
|---|---|---|
| Студент | Без входа. Один раз выбирает подразделение, группу и подгруппу | Свои пары: сегодня, завтра, неделя. Изменения. Подписка на календарь |
| Преподаватель | Без входа. Находит себя поиском | Свои пары по всем группам. Свободные аудитории сейчас |
| Администратор | В демо — кнопка «Войти как администратор». Позже — логин в PocketBase | Вносит расписание и изменения в своём подразделении. Журнал, публикация, экспорт |

Администраторов может быть несколько, у каждого своя зона (подразделения). Чужое он видит, но не правит.

## Стек и устройство

- Ванильный JS, нативные ES-модули, **без сборщика и без npm-зависимостей в рантайме**. Деплой: `git push` → GitHub Pages.
- Модули с первого дня. Ни один файл не больше ~400 строк. Глобального мутабельного состояния нет: всё идёт через `src/data/api.js`.
- `src/data/api.js` — единственная точка доступа к данным. В демо он работает поверх `demo-store.js` (сид + `localStorage`). Позже под ним будет PocketBase, и интерфейс при этом не меняется.
- `src/domain/` — чистые функции без DOM: развёртка правил дат, звонки, **проверка конфликтов**, генерация .ics. Тесты: `node --test` (встроен в Node, зависимостей не нужно). Этот код потом переедет на сервер как есть.
- Студенческая часть читает только «опубликованное» представление (в боевой версии это статические `group-*.json` и `.ics`). Админка пишет через api. Не смешивать.

## Дизайн

- Строго по брендбуку МГПУ, подробности в скилле `.Codex/skills/mgpu-brand`. Токены лежат в `assets/brand.css`, цвета в коде задаём **только** через токены.
- Красный — только акцент. Красных фонов и заливок крупных площадей нет.
- Шрифт Museo Sans Cyrillic (woff2 лежат локально), запасной — Arial/Helvetica. Google Fonts и прочие внешние CDN не используем.
- Сначала мобильная вёрстка: студент сидит с телефона. С 900px таб-бар превращается в сайдбар: админ работает за компьютером.
- Apple HIG как ориентир: тап-зоны от 44px, сетка отступов 4px, `prefers-reduced-motion`, тёмная тема.
- Узнаваемый элемент — дуги и кольца из логотипа: индикатор загрузки, пустые состояния, прогресс текущей пары.

## Модель данных

Полностью в `docs/02-model-dannyh.md`. Три вещи, которые нельзя упростить, иначе после демо придётся всё ломать:

1. **Занятие привязано к конкретным датам**, а не к «чётной или нечётной неделе». Так устроено реальное расписание ВО: «07.09, 21.09», «с 09.09 по 28.10; с 11.11 по 23.12».
2. **Сетка звонков своя у каждого подразделения и может отличаться по дням.** У ВО пары по 80 минут, у СПО уроки по 45, в субботу у СПО своя сетка.
3. **Конфликты считаются по реальному времени и дате**, а не по номеру пары: ВО и СПО делят один корпус.

## Как работать

- Перед кодом — короткий план. Superpowers: `brainstorming` → `writing-plans` → `executing-plans`.
- `src/domain/` пишем через TDD (`test-driven-development`): сначала тесты на конфликты и развёртку дат по случаям из `docs/02`.
- Вёрстку проверяем на живой странице в браузере на ширине 375, 768 и 1280, в светлой и тёмной теме (`webapp-testing`). По CSS «на глаз» не судим.
- Перед сдачей этапа: `verification-before-completion` и аудит `web-design-guidelines`.
- `catch` без логирования запрещён: это урок «Полки».
- Реальные ФИО преподавателей из `samples/` в демо-данные не переносим. Всех людей придумываем.

## Открытые вопросы (вне кода)

- Веб-лицензия на Museo Sans Cyrillic: есть ли она у МГПУ. Для демо используем файлы из комплекта брендбука.
- Иконка приложения: логотип менять нельзя, а в квадрате 60×60 он нечитаем. Для демо ставим `logo-ru-3` без изменений, боевую иконку согласуем с отвечающими за фирменный стиль.
- В каком формате МЭШ и 1С принимают расписание на импорт.
- Подключён ли МГПУ к «Расписанию занятий» в MAX.
- `samples/` в git не коммитим (там реальные ФИО), в `.gitignore` уже добавлено.
- Шрифт в публичном репозитории GitHub Pages — это фактически публикация файлов шрифта. Для закрытого показа допустимо, но вопрос лицензии надо закрыть до того, как ссылка уйдёт шире руководства.
